Privacy Policy

Last updated: 16 November 2026

Shorts Reply Bot is a personal tool that only the owner of one YouTube channel uses. It is not offered to the public.

What data it uses

Through the YouTube Data API, the bot reads the owner's recent uploads and the public comments on them. It reads each commenter's display name, the comment text and the comment ID. It uses this only to write and post replies on the owner's channel.

How the data is processed

The comment text is sent to an AI service (Anthropic's Claude API) to draft the reply. The bot keeps only a list of comment IDs it has already handled, so it doesn't reply twice. It stores no other comment content.

Sharing

No data is sold, shared or used for ads. The owner's sign-in token is stored privately and is used only to post the owner's own replies.

Google API Services

The bot's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The bot uses YouTube API Services, and the Google Privacy Policy also applies.

Removing access

The owner can remove the bot's access at any time at myaccount.google.com/permissions.
